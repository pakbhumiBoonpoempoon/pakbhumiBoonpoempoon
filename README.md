### 🔭 Featured project

**[ProxymanClone](https://github.com/pakbhumiBoonpoempoon/Mock-api)** — a Proxyman/Charles-style
HTTP(S) debugging proxy for macOS, written from scratch.
- Go MITM proxy core + embedded React UI, shipped as a menu bar app
- Decrypts HTTPS with a self-generated root CA; one-click trust for the Mac,
  iOS Simulator and Android emulator
- **Map Local** — mock or override any API response (inline JSON or a hot-reloaded
  local file), matched by method + host/path globs
- Separate listeners + a **Devices / iOS / Android** filter so simulator traffic
  is easy to isolate
- WebSocket & SSE pass-through, `make install` for a no-terminal launch

`Go` · `React` · `TypeScript` · `goproxy` · `crypto/tls`
